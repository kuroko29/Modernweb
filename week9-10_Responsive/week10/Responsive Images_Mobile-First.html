Responsive Images

1. รูปภาพที่ไม่ใช้ Responsive

กำหนดความกว้างตายตัว 700px รูปอาจล้นหน้าจอเมื่อเปิดบนมือถือ

img {
    width: 700px;
}

ลองเปิด Developer Tools และดูบนหน้าจอมือถือ จะเห็นว่ารูปล้นออกด้านข้าง

2. รูปภาพแบบ Responsive

ใช้ความกว้างเต็มพื้นที่ แต่ไม่เกินขนาดสูงสุดของรูป

img {
    max-width: 100%;
    height: auto;
}

รูปจะย่อให้พอดีกับหน้าจอ และยังคงสัดส่วนเดิมไว้
